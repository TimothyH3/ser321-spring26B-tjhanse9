You can make the following GET requests

  • /file/sample.html -- returns the content of the file sample.html
  • /json -- returns a json of the /random request
  • /random -- returns index.html

  • /multiply -- Multiplies two numbers together.
    Example: /multiply?num1=5&num2=4

  • /github -- Fetches a list of public repositories for a specified GitHub user.
    Example: /github?query=users/amehlhase316/repos

  • /madlibs -- Generates a funny Mad Libs sentence. Requires two arguments: a noun and an adjective.
    Example: /madlibs?noun=potato&adjective=angry

  • /tempconvert -- Converts a temperature between Celsius and Fahrenheit. Requires a temprature number and the scale you are converting from (C or F).
    Example: /tempconvert?temp=100&scale=C
